# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and releases use semantic versioning.

## [0.1.0] - 2026-08-22

### Added

- Local Carbon Web Components operations console.
- Read-only standard and deep Ubuntu analyzers.
- Allowlisted privileged cleanup agent over a Unix socket.
- Explicit plan review, hash validation and typed confirmation.
- Seven-day quarantine, restore workflow and expiry timer.
- SQLite audit history, systemd hardening, CI and automated releases.
